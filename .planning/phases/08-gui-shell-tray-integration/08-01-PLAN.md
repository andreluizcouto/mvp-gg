5. Add `remove_notification(self)` convenience method that wraps `self._icon.remove_notification()`

**Updated `__init__`:**
```python
def __init__(self, on_quit: Callable, on_show: Callable | None = None):
    self._state = "waiting"
    self._detail = ""
    self._on_quit = on_quit
    self._on_show = on_show
    self._icon: pystray.Icon | None = None
    self._lock = threading.Lock()
```

**New methods:**
```python
def _show_window(self, icon, item) -> None:
    """Triggered by left-click (default action) or 'Abrir MVPApp' menu item."""
    if self._on_show:
        self._on_show()

def notify(self, message: str, title: str = "MVPApp") -> None:
    """Show tray balloon notification. Thread-safe."""
    if self._icon:
        self._icon.notify(message, title)

def remove_notification(self) -> None:
    """Remove any active tray notification."""
    if self._icon:
        self._icon.remove_notification()
```

**Updated `_build_menu()`:**
```python
def _build_menu(self) -> pystray.Menu:
    return pystray.Menu(
        pystray.MenuItem(
            "Abrir MVPApp",
            self._show_window,
            default=True,
            visible=True,
        ),
        pystray.Menu.SEPARATOR,
        pystray.MenuItem(
            lambda item: _STATUS_LABELS.get(self._state, ""),
            None,
            enabled=False,
        ),
        pystray.Menu.SEPARATOR,
        pystray.MenuItem(
            "Ver analise",
            self._open_site,
            enabled=lambda item: self._state in ("uploading", "ready"),
        ),
        pystray.Menu.SEPARATOR,
        pystray.MenuItem(
            "Minimapa a esquerda",
            self._toggle_left,
            checked=lambda item: get_config().get("minimap_left", False),
        ),
        pystray.MenuItem(
            "Minimapa grande",
            self._toggle_large,
            checked=lambda item: get_config().get("minimap_large", False),
        ),
        pystray.Menu.SEPARATOR,
        pystray.MenuItem("Sair", self._quit),
    )
```

**New test:**

```python
def test_hide_tray_notification_roundtrip(tmp_path):
    """hide_tray_notification persists through write → read cycle."""
    from app_config import get_config, save_config, update_config

    save_config({"minimap_left": False, "minimap_large": False}, config_dir=str(tmp_path))
    result = update_config("hide_tray_notification", True, config_dir=str(tmp_path))
    assert result["hide_tray_notification"] is True

    cfg = get_config(config_dir=str(tmp_path))
    assert cfg["hide_tray_notification"] is True
```

## Warnings

- ⚠️ The `get_config()` whitelist is the primary bug — if you only update `_DEFAULTS` but not the return dict, `hide_tray_notification` will be silently dropped on read-back.
- ⚠️ Do NOT change TrayIcon's existing callback signatures `(self, icon, item)` — pystray requires this.
- ⚠️ The `on_show` parameter must be optional (backward compatible).
