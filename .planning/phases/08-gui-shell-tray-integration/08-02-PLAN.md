    - `set_appearance_mode("dark")` MUST be called BEFORE `ctk.CTk()` — otherwise dark theme may not apply to window frame on Windows
    - `app._iconbitmap_method_called = True` MUST be set after `iconphoto()` — otherwise CTk overrides your custom icon after 200ms with its default gear icon (Pitfall 2)
    - `update_idletasks()` MUST be called before centering geometry — otherwise `winfo_width()`/`winfo_height()` returns 1 (Pitfall from research)
    - ALL tkinter calls from pystray thread MUST go through `app.after(0, fn)` — direct calls cause Tcl errors or silent corruption
    - PhotoImage references MUST be stored as attributes — Python GC destroys unreferenced images causing blank display (Pitfall 3)
    - Use `withdraw()` NOT `iconify()` — iconify minimizes to taskbar (still visible), withdraw fully hides (correct for tray behavior per D-06)
    - Call `tray.remove_notification()` in show_window — otherwise balloon and restored window are visible simultaneously (Pitfall 5)
