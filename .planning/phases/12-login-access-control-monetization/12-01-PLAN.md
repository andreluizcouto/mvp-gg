## NECESSIDADES EXTREMAS

- Supabase Auth pode ser usado no bootstrap, mas com arquitetura anti-lock-in.
- Backend é a fonte de verdade para authn/authz/entitlement/quota; frontend não decide acesso.
- Token nunca em texto puro no storage persistente; hash + revogação obrigatórios.
- Token curto + refresh rotativo + sessão revogável por dispositivo.
- Fail-closed: qualquer erro de sessão/entitlement bloqueia análise.
- Base pronta para exportação e migração futura de provedor sem quebra de regra de negócio.
