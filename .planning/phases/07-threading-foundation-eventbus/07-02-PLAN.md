from typing import Any, Callable

    **5. Rewrite `main()` completely** — replace current 2-thread main with 3-thread bootstrap:
    ```python
    def main() -> None:
        stop_event = threading.Event()
        event_bus = EventBus()

        # 1. Create CTk window on main thread (MUST be main thread)
        app = ctk.CTk()
        app.title("MVPApp")
        app.geometry("400x500")
        app.withdraw()  # Start hidden — Phase 8 will add the visible shell

        def on_quit():
            """Called from any thread to initiate clean shutdown."""
            logger.info("Encerrando CoachApp...")
            stop_event.set()
            app.after(0, app.quit)  # Schedule mainloop exit on main thread

        # 2. Create and start tray on background thread
        tray = TrayIcon(on_quit=on_quit)
        tray.run_detached()  # Non-blocking — spawns Win32 message loop thread

        # 3. Start asyncio loop on daemon thread
        async_thread = threading.Thread(
            target=_run_async_loop,
            args=(tray, stop_event, event_bus),
            daemon=True,
        )
        async_thread.start()

        # 4. Start EventBus polling (bridges queue → main thread)
        event_bus.start_polling(app)

        # 5. Enter main loop (blocks until app.quit())
        app.mainloop()

        # 6. Cleanup after mainloop exits
        tray.stop()
        async_thread.join(timeout=5.0)
        try:
            app.destroy()
        except Exception:
            pass  # Window may already be destroyed
        logger.info("CoachApp encerrado.")
    ```

    **Critical design notes:**
    - `app.withdraw()` hides the window on startup — the app still appears as a tray-only app (same as current behavior). Phase 8 will add the visible window shell.
    - `on_quit()` uses `app.after(0, app.quit)` to safely schedule mainloop exit from any thread — this is the ONLY thread-safe way to exit tkinter mainloop from a background thread.
    - `daemon=True` on asyncio thread ensures it dies if main thread exits unexpectedly.
    - `app.destroy()` is wrapped in try/except because if shutdown is triggered by window close, the app may already be destroyed.

    **6. Do NOT modify** `_upload()`, `_poll_status()`, `_build_auth_headers()`, or any constants (BACKEND_URL, LOCAL_APP_TOKEN, POLL_INTERVAL, _BASE_DIR, logging setup). These remain exactly as-is.
